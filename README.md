# tkg

A clean React frontend monorepo starter modeled on the `dai-ui` workspace conventions.

## Stack

- Yarn 1 workspaces
- Lerna with Nx integration
- React and Vite
- TypeScript
- Vitest
- Oxlint

## Development

```sh
yarn install
yarn dev
```

The app is in `packages/app`.

## Checks

```sh
yarn lint
yarn test
yarn build
```
